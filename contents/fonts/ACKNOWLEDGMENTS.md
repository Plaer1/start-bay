Comic Clank builds on open fonts. Each upstream keeps its own copyright and license. This file does not relicense them. Pinned revisions and license texts are in [licenses/UPSTREAMS.md](licenses/UPSTREAMS.md).

## Source references

- **[Comic Neue](https://github.com/crozynski/comicneue)**, Craig Rozynski and The Comic Neue Project Authors. SIL OFL 1.1.
- **[Comic Mono](https://github.com/dtinth/comic-mono-font)**, dtinth, a fork of **[Comic Shanns](https://github.com/shannpersand/comic-shanns)** by Shannon Miwa. MIT. Studied for its monospacing approach; no code or outlines are used.
- **[Fira Code](https://github.com/tonsky/FiraCode)**, Nikita Prokopov and The Fira Code Project Authors, built on Fira Mono (Mozilla Foundation, Telefonica S.A.). SIL OFL 1.1.
- **[OpenDyslexic](https://opendyslexic.org)**, Abbie Gonzalez. SIL OFL 1.1, Reserved Font Name "OpenDyslexic". Comic Clank is not OpenDyslexic and does not use that name.

## Inspiration

Comic Sans (Vincent Connare, Microsoft) is the general inspiration for the comic-hand style. Comic Clank contains no Comic Sans outlines or data, and it is not affiliated with Microsoft.
